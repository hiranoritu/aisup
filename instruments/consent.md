# 研究への参加についての説明（見本）

### この研究について
生成AIを使ってC言語のプログラミングを学ぶときの、AIへの質問のしかたと回答の使い方を調べる研究です。

### 参加の内容
- 所要時間は約120分です。途中で中断しても、同じURLを開けば続きから再開できます（最初に開いてから24時間以内）。
- 練習 → 短いテスト → 課題 → 課題 → 短いテスト → アンケート の順に進みます。
- 課題中はこの画面のAIを使えます。**このシステム以外のAI（ChatGPTなど）は使わないでください。** 使ってしまった場合も不利益はありません。最後のアンケートで正直に教えてください。
- テストは成績評価には使いません。

### 記録するデータ
- エディタの操作（打鍵・貼り付け・実行）、AIへの質問と回答、テストとアンケートの回答、画面を離れた時間を記録します。
- 記録は匿名のIDで扱い、氏名とは結びつけません。
- AIへの質問文と課題のコードは、回答の生成のため外部のAI事業者（OpenAI）に送信されます。質問文に個人情報を書かないでください。

### 参加の任意性と撤回
参加は任意です。途中でやめても不利益はありません。参加後のデータの削除を希望する場合は、実験者（連絡先：＿＿＿＿）にご連絡ください。
