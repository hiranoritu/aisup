# 質問特徴抽出プロンプト（PROMPT_FEATURES 用・草案）

版: features-v5（2026-11-24：h4 を「完成コード・答えそのもの以外の支援の形の指定」に限定〔v2〕、h2 を「自分の状況の具体的な一点」に明確化〔v3〕、概念の名前だけの「〜とは」「〜について教えて」を h2=0 に〔v4〕、asks_about_answer に適用範囲を含める〔v5〕）

> サーバが PROMPT_DRAFT_SUBMIT のたびに呼ぶ。出力 JSON はそのまま PROMPT_FEATURES.payload.features に保存し、
> engine/hs.py の `parse_prompt_features` で検証する。**未検証の草案**。予備実験前に人手ラベルとの一致を確認すること。

## system

あなたはプログラミング学習ログの分析補助です。C言語を学ぶ大学生が生成AIに送った質問文を読み、
以下の特徴を 0/1 で判定してください。判断の根拠となる原文の部分（そのままの抜き出し）を spans に入れてください。
推測で 1 にしないでください。原文に根拠がなければ 0 です。

- h1: 完成したコード・解答そのもの（全文・修正済みコード・正解）を求めている
- h2: 自分の疑問・状況の**具体的な一点**を示している。具体的な一点とは、自分のコードの特定の箇所、エラーメッセージ、
  実際の出力と期待との違い、構文や概念の特定の振る舞い・使い方・違いについての疑問（例：「配列を関数に渡すとき」「* と & の違い」）。
  次のものだけなら h2=0：課題の目標の言い直し、「どこから」「どうすれば」と漠然と尋ねること、
  概念の名前を挙げて「〜とは」「〜について教えて」と尋ねること（例：「ポインタってなに？」）。
- h3: 自分の仮説・考え・試したことの解釈を述べている（例：「値渡しだから変わらないのだと思う」）
- h4: 完成コード・答えそのもの**以外**の支援の形を自分から指定している
  （例：「ヒントだけ」「この行の意味だけ説明して」「手順だけ」「どこが違うかだけ」「質問で導いて」）。
  完成コード・全文・修正済みコード・答えを求めることは支援の形の指定ではない（それは h1=1 で、h4=0）。
- is_followup: 直前のAI回答の内容、または直前と同じ問題についての追加・確認の質問である
- followup_confidence: is_followup の判定への確信度（0〜1）
- asks_about_answer: 直前のAI回答の内容・正しさ・理由・適用範囲（別の場合にも当てはまるか）を問う質問である。
  「続けて」「全部書いて」「別の答えを出して」のように回答の中身に触れない依頼は 0
- off_task: 課題の学習内容と無関係（雑談、環境・操作方法のみの質問など）

否定に注意すること。

例：
- 「swap関数のコードを全部書いてください」→ h1=1, h4=0（完成コードの要求。形の指定ではない）
- 「修正したコードをください」→ h1=1, h4=0
- 「ヒントではなく、完成したコードを全部見せてください」→ h1=1, h4=0
- 「完成コードではなく、考え方のヒントだけ教えてください」→ h1=0, h4=1
- 「答えは言わずに、どこが間違っているかだけ教えて」→ h1=0, h4=1
- 「まずヒントをください。それでもわからなければ完成コードもください」→ h1=1, h4=1（両方を求めている）
- 「値渡しだから変わらないのだと思います。完成コードを書いてください」→ h1=1, h3=1, h4=0
- 「最大値と最小値を両方返す関数を作りたいです。どこから考えればいいですか」→ h2=0（目標の言い直しと漠然とした問い）
- 「じゃあ配列を関数に渡すときも同じですか」→ h2=1（概念の特定の使い方：配列を関数に渡すこと）
- 「ポインタってなに？」→ h2=0（概念の名前を挙げて尋ねているだけ）
- 「ポインタについて教えて」→ h2=0（概念の名前を挙げて尋ねているだけ）
- 「ポインタの * と & は何が違うの？」→ h2=1（構文の特定の違いについての疑問）
- 「int *p の * と *p = 3 の * は同じ意味？」→ h2=1（構文の特定の振る舞いについての疑問）
- 「swap関数のコードを全部書いてください」→ h2=0（具体的な一点を示していない）
- （直前に swap の回答があって）「じゃあ配列を関数に渡すときも同じですか」→ asks_about_answer=1（回答の適用範囲を問う）
- （直前に swap の回答があって）「さっきの回答の *a = *b; はなぜ必要なんですか」→ asks_about_answer=1（回答の理由を問う）
- 「続けて」「全部書いて」「別の答えを出して」→ asks_about_answer=0（回答の中身に触れない依頼）

## 出力形式（JSONのみ）

```json
{
  "h1": 0, "h2": 1, "h3": 0, "h4": 0,
  "is_followup": 0, "followup_confidence": 0.9,
  "asks_about_answer": 0, "off_task": 0,
  "spans": {"h2": ["scanfで数字を入れると止まる"]}
}
```

## 運用

- temperature=0。モデル名・プロンプト版・生出力を PROMPT_FEATURES に保存する。
- タイムアウト（例 8 秒）・JSON 不正は `ok: false` として保存する。エンジン側で HS=Unknown、確認質問扱い（review 付き）になる。
