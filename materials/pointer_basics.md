# ポインタの基本

### 1. 変数とアドレス
変数はメモリのどこかに置かれています。その場所を **アドレス** といいます。
変数名の前に `&` を付けると、その変数のアドレスが得られます。

```c
int a = 10;
printf("%d\n", a);    /* 10（a の値） */
/* &a は「a のアドレス」 */
```

### 2. ポインタ変数
アドレスをしまっておく変数を **ポインタ** といいます。宣言では型の後ろに `*` を付けます。

```c
int a = 10;
int *p;      /* p は「int を指すポインタ」 */
p = &a;      /* p に a のアドレスを入れる → p は a を指す */
```

### 3. 間接参照 `*`
ポインタの前に `*` を付けると、**ポインタが指す先の変数** を表します。

```c
int a = 10;
int *p = &a;
printf("%d\n", *p);   /* 10（p が指す先＝a の値） */
*p = 20;              /* p が指す先＝a に 20 を入れる */
printf("%d\n", a);    /* 20 */
```

| 書き方 | 意味 |
|---|---|
| `&a` | a のアドレス |
| `int *p` | p は int を指すポインタ（宣言） |
| `*p` | p が指す先の変数 |

### 4. 関数にアドレスを渡す
C の関数の引数は **値渡し** です。関数の中で引数を書き換えても、呼び出し元の変数は変わりません。

```c
void add_one(int x) {
    x = x + 1;          /* 書き換わるのはコピーの x だけ */
}
```

呼び出し元の変数を関数の中から書き換えたいときは、**アドレスを渡し**、関数の中で `*` を使います。

```c
#include <stdio.h>

void twice(int *p) {
    *p = *p * 2;        /* p が指す先（呼び出し元の n）を 2 倍にする */
}

int main(void) {
    int n = 4;
    twice(&n);          /* n のアドレスを渡す */
    printf("%d\n", n);  /* 8 */
    return 0;
}
```

### 5. 配列とポインタ
配列名は、多くの場面で **先頭の要素のアドレス** として扱われます。

```c
int b[3] = {5, 6, 7};
int *q = b;            /* q は b[0] を指す */
printf("%d\n", *q);        /* 5 */
printf("%d\n", *(q + 1));  /* 6（b[1] と同じ） */
printf("%d\n", q[2]);      /* 7（b[2] と同じ） */
```

### よくある間違い
- `int *p;` と宣言しただけで `*p = 1;` とする（p がどこも指していない）。
- `scanf("%d", x);` のように `&` を忘れる（`scanf` にはアドレスを渡す）。
- `*p` と `p` の取り違え（指す先の値か、アドレスそのものか）。
