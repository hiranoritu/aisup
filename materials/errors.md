# エラーメッセージの読み方

実行結果の欄に出るメッセージの読み方です。メッセージは英語ですが、**行番号**と**キーワード**を見れば多くは見当がつきます。

### 読み方の基本
```
main.c:4:5: error: expected ',' or ';' before 'printf'
```
- `main.c:4:5` … 4 行目の 5 文字目あたり
- `error` … コンパイルできない誤り（実行されません）
- `warning` … 実行はできるが、誤りの可能性が高い箇所
- `note` … 上のエラーや警告についての補足

### よく出るコンパイルエラー
| メッセージの一部 | 意味 | よくある原因 |
|---|---|---|
| `expected ',' or ';' before …` | ここより前に `;` が必要 | **前の行**の行末の `;` 忘れ |
| `'y' undeclared` | y という名前が宣言されていない | 変数の宣言忘れ・つづりの誤り |
| `expected declaration or statement at end of input` | ファイルの最後で何かが足りない | `}` の閉じ忘れ |

### ポインタでよく出る警告
| メッセージの一部 | 意味 |
|---|---|
| `makes pointer from integer without a cast` | ポインタ（アドレス）を渡すべき所に、ふつうの int を渡している。`&` の付け忘れが多い |
| `expected 'int *' but argument is of type 'int'` | 関数は `int *`（アドレス）を受け取るのに、`int`（値）を渡している |
| `format '%d' expects argument of type 'int *'` | `scanf` に変数のアドレスではなく値を渡している（`&` 忘れ） |
| `'p' is used uninitialized` | 値（ポインタならアドレス）を入れる前に使っている |

**警告が出ても実行はできますが、ポインタの警告はほぼ確実に誤りです。** 無視せずに直しましょう。

### 実行時エラー（実行してから出るもの）
| メッセージの一部 | 意味 |
|---|---|
| `index 3 out of bounds for type 'int [3]'` | 要素が 3 個の配列の `[3]`（範囲外）を使った。添字は 0〜2 |
| `load of null pointer` | どこも指していない（NULL の）ポインタの指す先を読もうとした |
| `AddressSanitizer: SEGV` | 読み書きしてはいけないメモリを使った。初期化していないポインタの `*p` が多い |
| `load of misaligned address` | 正しいアドレスではない値をポインタとして使った（`&` 忘れなど） |

実行時エラーのメッセージにも `main.c:4:5` のように**原因の行**が書かれています。まずその行を見ましょう。

### 実行結果の欄の補足
- 「時間制限を超えたため停止しました」… 無限ループの可能性があります（ループの条件を確認）。
- 標準入力が足りないと、`scanf` が値を読めずに変な値のまま進むことがあります。実行前に入力欄を確認しましょう。
