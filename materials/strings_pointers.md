# 文字列とポインタ

### 1. 文字列は char の配列
C の文字列は `char` の配列で、最後に **終端文字 `'\0'`** が入っています。

```c
char s[] = "cat";
/* s[0]='c', s[1]='a', s[2]='t', s[3]='\0' の 4 要素 */
```

| 添字 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| 中身 | `'c'` | `'a'` | `'t'` | `'\0'` |

`'\0'` は「ここで文字列が終わり」という印です。文字列を扱う関数は、`'\0'` が来るまで読み進めます。

### 2. char へのポインタ
配列と同じく、文字列の名前は先頭の文字のアドレスとして使えます。

```c
char s[] = "cat";
char *p = s;          /* p は s[0]（'c'）を指す */
printf("%c\n", *p);   /* c */
p++;                  /* p を 1 文字先へ進める → s[1] を指す */
printf("%c\n", *p);   /* a */
```

`p++` は「ポインタが指す場所を 1 つ先の要素に進める」という意味です。`*p` の値（文字）が増えるわけではありません。

### 3. 文字列を最後までたどる
`'\0'` に着くまでポインタを進めると、文字列を 1 文字ずつ調べられます。次の例は 1 文字ずつ表示します。

```c
#include <stdio.h>

void print_each(const char *s) {
    for (const char *p = s; *p != '\0'; p++) {
        printf("[%c]", *p);
    }
    printf("\n");
}

int main(void) {
    print_each("cat");   /* [c][a][t] */
    return 0;
}
```

### 4. 関数の引数の `const char *`
`const char *s` は「s が指す文字列を、この関数の中では書き換えない」という約束です。
文字列を読むだけの関数では `const` を付けるのが一般的です。

### 5. scanf で文字列と文字を読む
```c
char s[100];
char c;
scanf("%99s %c", s, &c);   /* s は配列なので & を付けない。c は 1 文字の変数なので & を付ける */
```
- `%99s` は空白までの単語を最大 99 文字読みます（最後の `'\0'` の分を空けておく）。

### よくある間違い
- `'\0'` を調べずに進み続け、配列の外を読んでしまう。
- `*p++` と `(*p)++` の取り違え（前者はポインタを進める、後者は指す先の値を 1 増やす）。
- `'a'`（1 文字）と `"a"`（文字列）の取り違え。
