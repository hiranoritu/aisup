管理トークン

サーバ起動時に環境変数 ADMIN_TOKEN に設定した文字列を入力してください。

使い方

  1. 「参加者の登録」で群を選んで登録する（群は学習者には表示されません）。
  2. 表の「URLをコピー」で学習者URLを取得し、学習者のブラウザで開く。学習者画面は開始まで「お待ちください」と表示されます。
  3. 「開始」を押すと最初の課題（導入）が始まる。以降は「次の課題へ」で 導入 → 主課題1 → 主課題2 → 後続課題 → 終了 と進みます。支援が出るのは主課題だけです。
  4. 「判定」で各サイクルの状態（HS×RU）と介入判断を確認できます。終了後は「ログと判定結果をダウンロード」。
