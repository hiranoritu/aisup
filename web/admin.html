管理トークン

サーバ起動時に環境変数 ADMIN_TOKEN に設定した文字列を入力してください。

使い方（遠隔・非同期の実施）

  1. 「参加コードを発行」で1人ずつ発行し、表示された URL を参加者にメールで送ります。群は割付表（ブロック無作為化）の順に自動で決まり、参加者には表示されません。
  2. 参加者は都合のよい時間に URL を開き、同意 → 環境確認 → 練習 → 事前テスト → 課題 → 課題（後半）→ 事後テスト → アンケートと自動で進みます。
  3. この画面で進行状況を確認できます（5秒ごとに更新）。問題があれば「停止」で参加を止められます。
  4. 氏名・メールと参加コードの対応表はこのサーバに置かず、別に保管してください。
